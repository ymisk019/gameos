## 🌟 نظرة عامة | Overview

**Yazan Game OS** هو نظام تشغيل حقيقي مستقل تمامًا تم بناؤه من الصفر (from scratch) دون الاعتماد على لينكس (Linux) أو نواة جاهزة، موجّه خصيصًا لتشغيل الألعاب الكلاسيكية ثنائية الأبعاد (2D Games) بواجهة رسومية خفيفة وسريعة وحديثة.

يجمع النظام بين الأداء العالي جداً والاستهلاك فائق الانخفاض للذاكرة والتخزين، مع واجهة مستخدم رسومية أنيقة تدعم اللغتين **العربية** و**الإنجليزية**، ونظام إدارة نوافذ متكامل، و5 ألعاب كلاسيكية كاملة وممتعة وجاهزة للعب فوراً، بالإضافة إلى متجر ومدير ألعاب يتيح تحميل ألعاب جديدة مستقبلاً بصيغة **`.YGP`** دون الحاجة لإعادة بناء النظام أو ملف الـ ISO!

## 🚀 المميزات الرئيسية | Key Features

1. **نواة مستقلة تماماً (Pure Bare-Metal C++ Kernel)**:
   - مبنية بلغة C++ مع مجمّع Assembly x86.
   - إدارة كاملة للذاكرة: مخصص الصفحات وإدارة الـ Heap (`kmalloc` / `kfree` / C++ `new` و `delete`).
   - معالجة المقاطعات عبر GDT و IDT ومتحكم PIC 8259 ومؤقت PIT بتردد 100Hz.
   - نظام طاقة حقيقي: إيقاف التشغيل التلقائي (Shutdown عبر ACPI/APM) وإعادة التشغيل (Reboot عبر متحكم 8042).

2. **واجهة رسومية احترافية وخفيفة (Modern Lightweight GUI)**:
   - محرك رسومات VESA VBE بدقة **800x600 بـ 32-bit True Color** مع دعم التخزين المؤقت المزدوج (Double-Buffering) لمنع التقطيع.
   - سطح مكتب تفاعلي مع 4 خلفيات أنيقة (Cyber Neon, Deep Space, Retro Sunset, Minimal Dark).
   - قائمة ابدأ (Start Menu) كاملة مع تصنيفات التطبيقات وإجراءات إيقاف وتشغيل النظام.
   - شريط مهام تفاعلي (Taskbar) يحتوي على زر ابدأ، النوافذ النشطة، ساعة النظام الحقيقية (CMOS RTC)، مبدل الصوت، ومبدل اللغة (AR / EN).
   - نظام نوافذ كامل يدعم السحب بالفأرة، التكبير والتصغير، الإغلاق، وتعدد المهام.

3. **دعم ثنائي اللغة (العربية والإنجليزية)**:
   - محرك خطوط مخصص يدعم الأبجدية العربية وتشكيل الحروف والكتابة من اليمين إلى اليسار (RTL).
   - إمكانية التبديل الفوري بين العربية والإنجليزية بنقرة واحدة من شريط المهام أو الإعدادات.

4. **دعم عتادي كامل (Hardware Drivers)**:
   - لوحة المفاتيح عبر منفذ PS/2 مع دعم اختصارات التحكم.
   - فأرة PS/2 مع مؤشر سهم فائق الدقة والاستجابة.
   - مكبر الصوت المدمج (PC Speaker Synthesizer) لتوليد مؤثرات صوتية حقيقية للألعاب (قفز، ليزر، محرك، تصادم، فوز، وألحان إقلاع).
   - دعم أذرع التحكم (Gamepad / Joystick) عبر منفذ Gameport والتعيين التلقائي لمفاتيح لوحة المفاتيح.

5. **مدير الألعاب ومتجر التطبيقات (Game Manager & Store)**:
   - مكتبة تستعرض جميع الألعاب المثبتة مع تفاصيلها وطريقة اللعب.
   - دعم صيغة **YGP (Yazan Game Package)** لإضافة ألعاب مستقبلية إلى مجلد `/store` وتشغيلها ديناميكياً دون إعادة تجميع النظام!

6. **نظام ملفات افتراضي (Virtual File System - VFS)**:
   - بنية أدلة شجرية متكاملة (`/`, `/games`, `/system`, `/wallpapers`, `/store`, `/docs`).
   - مدير ملفات رسومي لتصفح الملفات وعرض أحجامها وأنواعها.

## 🛠️ كيفية بناء وتشغيل النظام | Building & Running

### 1. تشغيل البناء وإنتاج الـ ISO تلقائياً
باستخدام أداة البناء المستقلة:
```bash
python3 tools/build_iso.py yazan-game-os.iso
```
أو باستخدام الـ Makefile (يتطلب `nasm`, `g++`, `grub-mkrescue`):
```bash
make
```

### 2. فحص والتحقق من صحة ملف الـ ISO
```bash
python3 tests/test_kernel.py yazan-game-os.iso
```

### 3. التشغيل عبر محاكي QEMU
```bash
qemu-system-i386 -cdrom yazan-game-os.iso -soundhw pcspk -m 256M -vga std
```
أو على محاكي 64-bit:
```bash
qemu-system-x86_64 -cdrom yazan-game-os.iso -soundhw pcspk -m 256M -vga std
```

### 4. الإقلاع على كمبيوتر حقيقي (Real PC Hardware)
- انسخ ملف `yazan-game-os.iso` إلى فلاشة USB باستخدام برنامج **Rufus** (اختر وضع DD أو ISO) أو عبر الأمر:
  ```bash
  sudo dd if=yazan-game-os.iso of=/dev/sdX bs=4M status=progress && sync
  ```
- أعد تشغيل الكمبيوتر، ادخل إلى قائمة الإقلاع (Boot Menu بالضغط على F12 أو F11 أو ESC)، واختر الإقلاع من الفلاشة!

## 📦 إضافة ألعاب جديدة إلى المتجر (.YGP)

لإضافة لعبة جديدة إلى المتجر دون إعادة بناء النظام:
```bash
python3 tools/package_game.py my_game.ygp game_id "English Name" "الاسم بالعربي"
```
ضع الملف داخل دليل `/store` في نظام الملفات، ثم افتح **متجر الألعاب** وانقر على **فحص المتجر** لتثبيت اللعبة فوراً!

## ⚙️ متطلبات التشغيل الدنيا | Minimum Requirements

- **المعالج (CPU)**: معالج x86 متوافق (Intel Pentium أو AMD أو أحدث).
- **الذاكرة العشوائية (RAM)**: 64 ميجابايت كحد أدنى (النظام يستهلك أقل من 8 ميجابايت).
- **بطاقة الرسوميات**: متوافقة مع VESA VBE 2.0+ (دقة 800x600 بـ 24 أو 32 بت).
- **الإدخال**: لوحة مفاتيح وفأرة PS/2 أو USB عبر محاكي BIOS Legacy.
